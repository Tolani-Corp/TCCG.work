# Commercial Context

TCCG consumes the Tolani Commercial Context Plane v1 from `Tolani-Corp/TolaniCorp-HQ`.

Public acquisition should lead with the buyer outcome and project-review path, not internal design commentary. Agents must load `config/public-product-context.json` before editing marketing copy, capabilities, licenses, project claims, SEO, campaigns, or CTAs.

Licensing, bonding, insurance, service-area, client, project-size, savings, schedule, and award claims require current evidence. The primary conversion contract is `Request a project review` -> `TCCG Business Development` -> `project_qualification`.
